- specificity: project | local | state | national;
- source name, URL and as-of date;

- resolution rule.
Disclosed inputs have low = high = value unless a source gives a range. A test fails if any input lacks an entry.

- exit cap rate: by asset type;
- cost per MW, debt, capacity, schedule: disclosed, else blank;
- interest rate: SOFR plus cited spread;
- maintenance, labor, property tax: national benchmark.
