Redesign the SafeLoc Diligence Workbench homepage so a first-time visitor understands the product within ten seconds and has only two conceptual ways to begin:

1. Start from a public holding
2. Start from an infrastructure project

Preserve the current SafeLoc visual identity, color palette, typography and editorial character. Do not convert this into a generic SaaS landing page. Do not change the evidence data model, financial formulas, AI contracts, localStorage schemas or analysis-section functionality in this task.

PRIMARY OBJECTIVE

The homepage currently explains the AI infrastructure market well, but it does not immediately demonstrate the product. It also contains too many overlapping entry points:

* Start with NVIDIA
* Run the Stargate Case
* Analyze Another Project
* Start with the directory
* Six company cards
* A second Stargate CTA
* A second custom-project form
* Browse All Facilities

Simplify the hierarchy, show the product in the hero and preserve analytical depth through progressive disclosure.
