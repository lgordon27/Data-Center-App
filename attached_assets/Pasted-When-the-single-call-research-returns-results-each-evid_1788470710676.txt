When the single-call research returns results, each evidence item must show its sources and a confidence indicator. This is non-negotiable for a tool whose thesis is evidence quality.

WHAT THE AI MUST RETURN PER EVIDENCE ITEM:

Update the system prompt to require these fields for each of the 16 evidence items:

- id: the evidence variable ID
- value: what was found
- classification: one of the five tiers
- confidence: a number from 0 to 100 representing how confident the AI is in this classification based on the sources it found. 90-100 means multiple independent sources confirm. 70-89 means one strong source confirms. 50-69 means sources partially address this but not directly. Below 50 means weak or indirect evidence. 0 means nothing found.
- sources: an ARRAY of objects, each with:
  - title: the article or document name
  - url: the direct URL (from the web search citations)
  - publisher: the publication name (e.g., "TechCrunch", "SEC EDGAR", "Reuters")
  - date: publication date if available
  - relevance: one sentence on what this source says about this specific evidence variable
- reasoning: one sentence explaining the classification choice
- searchTermsUsed: what the AI searched to find this information (helps transparency)

WHAT THE FRONTEND SHOWS:

In the Evidence Room, for each AI-researched evidence item:

1. The classification badge and value (as currently shown)

2. A confidence bar next to the classification: a small horizontal bar filled to the confidence percentage, color-coded:
   - Green (80-100): strong source support
   - Yellow (50-79): partial source support
   - Red (0-49): weak or no source support

3. Below each item (visible by default for AI-researched items, not collapsed), show a compact source list:
   - Each source as a clickable link: "[Publisher] · [Title] · [Date]"
   - The one-sentence relevance note under each source
   - If no sources found: "No public sources identified for this variable"

4. A small "Search terms" toggle that shows what the AI searched. This is transparency about the research process itself.

ON THE CASE BRIEF (Screen 1) for AI-researched projects:

Add a research quality summary card:
- "Sources found: X unique sources across 16 variables"
- "Average confidence: X%"
- "Items with strong source support (80%+): X of 16"
- "Items with no sources: X of 16"

ON THE DECISION REVIEW (Screen 4):

When showing AI-researched evidence, the recommendation logic should factor in confidence scores. An item classified as "Management Assertion" with 90% confidence is more reliable than one classified as "Management Assertion" with 40% confidence. Show the confidence alongside the classification in the material gaps section.

The goal: a user looking at an AI-researched project can click any evidence item and see exactly which articles, filings, or reports the AI found, read a one-sentence summary of what each source says, and click through to the original source to verify it themselves. That is governed AI research. Not a black box that returns a classification badge.
