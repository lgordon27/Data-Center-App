---
name: Project posture vs. fund materiality
description: Defines the boundary between project evidence completeness and portfolio-level conclusions.
---

A single project evidence record can support a dynamic completeness posture for that project, but it cannot establish a fund-level risk tier or portfolio materiality.

**Why:** Translating site-level evidence classifications directly into HIGH, MODERATE, or LOW fund risk overstates what the analysis proves because portfolio exposure, concentration, and position sizing are not measured.

**How to apply:** Keep project completeness indicators distinct from qualitative issuer and holding connections, and explicitly state that portfolio materiality requires separate portfolio-level analysis.
