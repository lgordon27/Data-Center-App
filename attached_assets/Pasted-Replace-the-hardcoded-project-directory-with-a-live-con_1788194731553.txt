BACKEND:

Add a new proxy endpoint: GET /api/directory

This endpoint should:
1. Fetch from https://www.compute-atlas.com/api/facilities with appropriate query parameters to filter for data center facilities
2. Cache the response for 24 hours (this data updates daily, not in real time)
3. Transform each facility record into our directory format:
   - name: facility name
   - operator: operator/company
   - location: city/county from the facility record
   - state: state code
   - capacity: MW if available, "Undisclosed" if not
   - status: map Compute Atlas status to our categories (Operational, Under Construction, Planned, Paused, Blocked, Cancelled)
   - confidence: map their confidence field (confirmed, reported, rumored) to display labels
   - sourceUrl: the source citation URL from Compute Atlas
   - aiClassification: their AI angle classification (confirmed, likely, mixed_use, or null)
4. Return the transformed array sorted by state, then by capacity descending
5. If Compute Atlas API is unavailable, fall back to a hardcoded snapshot of 20-25 major projects (the list from our source research: Stargate, Kilby, Rock Creek, Dove Creek, CloudHQ, Meta El Paso, Google Ellis County, Fermi, Pacifico, plus Arizona and Virginia projects)

Also add: GET /api/directory/stats
Returns aggregate counts by state, by status, and total capacity. Sourced from Compute Atlas /api/stats endpoint.
