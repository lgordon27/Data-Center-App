---
name: Compute Atlas directory boundary
description: Durable boundary between facility discovery metadata and SafeLoc evidence/model inputs.
---

Compute Atlas records are discovery context only. Keep their provider freshness state and operator exposure mappings separate from the curated SafeLoc evidence source registry and synthetic economics.

**Why:** Directory capacity, status, confidence, and company/fund relationships are useful for finding projects, but they do not establish facility-level proof or disclosed transaction terms.

**How to apply:** Preserve explicit live, retained-provider, and embedded-snapshot states; never promote a directory field into Stargate evidence or a financial model input without a separate, attributable review.
