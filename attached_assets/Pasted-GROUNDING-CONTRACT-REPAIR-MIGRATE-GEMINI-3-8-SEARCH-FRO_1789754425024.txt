The last preflight used:

with:

and parsed:

- candidates[].groundingMetadata.webSearchQueries
- candidates[].groundingMetadata.groundingChunks[].web.uri

That is not the current documented Google Search grounding contract for Gemini 3.8 Flash.

Google’s current official Gemini API documentation shows:

POST https://generativelanguage.googleapis.com/v1beta/interactions

Request body:

{
  "model": "gemini-3.8-flash",
  "input": "...",
  "tools": [
    {
      "type": "google_search"
    }
  ]
}

The documented grounded response uses steps including:

- type: "google_search_call"
  - arguments.queries contains executed searches
- type: "google_search_result"
- type: "model_output"
  - content[] text blocks
  - content[].annotations[] entries with type: "url_citation"
  - each citation supplies its source URL

Treat this endpoint and schema mismatch as the leading diagnosis, but inspect the actual current files before editing.
