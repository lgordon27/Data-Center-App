---
name: Citation category routing
description: Routing invariant for provider citations with missing, unknown, mixed, or recognized category metadata.
---

Missing, empty, unusable, or wholly unknown citation category metadata means relevance is unresolved. Preserve the receipt in the audit; do not broadcast an ambiguous unlabeled passage to every analysis category. Exact-project retained text may enter assessment under the existing identity check. Mixed recognized and unknown labels retain recognized scope.

**Why:** Live arbitrary-project runs retained an exact-project source but sent empty analysis packets because provider citations had no category labels. A broad routing fix violated negative controls by sending generic unlabeled indexes to every category.

**How to apply:** Keep the actual availability gate and prompt filter consistent for exact-project context. Preserve unknown labels for audit, recognized category restrictions, and generic-index negative controls. Never infer identity, applicability, or eligibility from routing.
