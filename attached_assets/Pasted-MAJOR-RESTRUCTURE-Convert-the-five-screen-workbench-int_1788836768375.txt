MAJOR RESTRUCTURE: Convert the five-screen workbench into a single-page analysis with a persistent financial summary rail. Update all site navigation, references, and framing to reflect the new structure.

THE CORE CHANGE:

The current app has five separate hash routes (#brief, #evidence, #materiality, #decision, #advisor) that users navigate between using tabs and "Continue" buttons. This creates disconnection: changing evidence on one screen requires navigating to another screen to see the financial effect.

Replace the five-screen workbench with ONE continuous scrollable page at a single route (#analysis). The financial summary is always visible in a persistent left rail. The user scrolls through the analysis while the numbers update in real time beside them.

PERSISTENT LEFT RAIL (fixed position, always visible):

Width: approximately 280px on desktop. Collapses to a sticky top bar on mobile.

Contents:
- Project name (Stargate Abilene or custom project name)
- Tier badge (Tier 1 or Tier 2)
- Location
- Evidence Confidence: XX%
- Underwriting Baseline IRR: XX.X%
- Conservative Stress IRR: XX.X% (this is the number that moves when evidence changes)
- Evidence Quality Gap: X.X pts
- Recommendation Status: BLOCKED / CONDITIONAL / READY (with color: red/amber/green)
- Material Gaps: X items
- A compact evidence summary: X Verified, X Assertion, X Inference, X Assumption, X Missing

ALL of these values update in real time when any evidence classification changes anywhere on the page. The user changes a dropdown in the evidence section and watches the left rail numbers move without scrolling or navigating.

Below the metrics, show section navigation as anchor links:
- Project Overview
- Evidence
- Financial Impact
- Decision
- Advisor Lens

These smooth-scroll to the corresponding section. The currently visible section is highlighted as the user scrolls.

Below the section links:
- Reset to Default button
- Save Scenario button
- Compare Scenarios button

MAIN CONTENT AREA (scrollable, right of the rail):

All content flows as one continuous page. No tabs. No route changes. No "Continue to" buttons between sections.
