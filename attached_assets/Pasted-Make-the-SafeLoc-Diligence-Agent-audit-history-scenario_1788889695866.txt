Make the SafeLoc Diligence Agent, audit history, scenario snapshots and financial labels accurately describe what the system did. Batches 0–3 must already be complete.

AGENT STAGES

The current ten stages advance after short timed waits and build a deterministic package from existing context. They must not imply that ten searches or validations occurred.

For each stage:

* Complete it only after the named operation produces a recorded artifact, or
* Rename it as an existing-evidence review step.

Distinguish:

* Search executed
* Source retrieved
* Source accessible
* Evidence attached
* Claim validated
* Financially eligible
* Human accepted

Do not equate Verified-classified records with validated URLs.

CURATED SOURCES

Resolve curated `claimIds` into the same source and claim contract used for custom evidence. Do not drop claim-registry mappings when passing curated evidence to the agent.

AGENT PROPOSALS

Every consequential proposal must display:

* Current value/classification
* Proposed value/classification
* Raw source value and unit
* Normalized value and unit
* Supporting claim and passage
* Source eligibility
* Project/entity relevance
* Expected model effect
* Expected decision effect
* Confidence
* Accept
* Override
* Reject
* Leave unresolved

Before approval, the proposal must not modify accepted state.

After approval:

* Apply only the disclosed change.
* Recalculate affected metrics.
* Record before and after values.
* Make the change reversible.

A proposal that changes nothing must be labeled `No model change` rather than consequential.

AUDIT LINEAGE

Create one persisted event chain covering:

* Research proposal
* Normalization
* Acceptance
* Override
* Rejection
* Unresolved disposition
* Reversal
* Provider refresh
* Model recalculation

Each event must preserve:

* Event ID
* Actor
* Timestamp
* Evidence ID
* Before and after values
* Before and after units
* Before and after classifications
* Source snapshot
* Claim snapshot
* Model version
* Validation-policy version
* Reasoning
* Parent event

Reversal must append a reversal event. It must not erase or rewrite the original decision.
